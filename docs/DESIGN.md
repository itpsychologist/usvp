# Дизайн-система сайту УСВП

> Фаза 1 плану ([IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)). Живий UI-кіт і wireframes: `/styleguide/`
> (доступно, коли `STYLEGUIDE_ENABLED=True`; у dev увімкнено за замовчуванням, у prod вимкнено).

## Як працювати
```
uv run python manage.py tailwind build   # зібрати static/css/tailwind.css
uv run python manage.py tailwind watch   # перезбирати під час розробки
uv run python manage.py runserver        # http://localhost:8000/styleguide/
```
- Вхід Tailwind і всі токени: `assets/css/source.css` (поза `STATICFILES_DIRS`, щоб `collectstatic` не збирав сирий файл).
- Зібраний CSS (`static/css/tailwind.css`) і бінарник Tailwind (`.django_tailwind_cli/`) не комітимо. Версія CLI зафіксована в `TAILWIND_CLI_VERSION` (4.3.3).
- Компоненти: `templates/components/*.html`, підключаються через `{% include ... with ... %}`. Параметри описані в коментарі на початку кожного файла.

## Типографіка
- Шрифт **e-Ukraine** / **e-UkraineHead** (Мінцифри). Файли woff2 ще не додано: покладіть їх у `static/fonts/` і розкоментуйте `@font-face` у `source.css`. До того діє системний фолбек (Segoe UI / Roboto / Arial).
- Базовий розмір 18px (`html { font-size: 112.5% }`), тому всі `rem` у Tailwind масштабуються від 18px: `text-base` = 18px, `text-sm` = 15.75px, `text-lg` = 20.25px.
- Міжрядковий інтервал 1.5, ширина текстового блока `max-w-prose` = 68ch.
- Заголовки: H1 `text-3xl`/`md:text-4xl`, H2 `text-2xl`/`md:text-3xl`, H3 `text-xl`/`md:text-2xl`.

## Відступи, радіуси, тіні
8-pt сітка: кроки Tailwind 2 (8px), 4, 6, 8, 10, 12, 16. Радіуси `sm` 4px, `md` 8px (кнопки, поля), `lg` 12px (картки). Тіні `shadow-card` і `shadow-raised` (мегаменю). Ширина контейнера `max-w-site` = 80rem.

## Доступність у дизайн-системі
- **Фокус**: жовте кільце 3px + темна обвідка (видно на білому й синьому фоні); посилання у фокусі — жовтий фон і чорне підкреслення (патерн GOV.UK).
- **Цілі натискання** ≥ 44×44px (`min-h-11`) для кнопок, пунктів меню, перемикача мов.
- **Панель «Доступність»** у шапці: розмір шрифту (18 / 20 / 24px), високий контраст, підкреслення всіх посилань. Налаштування в `localStorage`, застосовуються до першого рендеру (`static/js/a11y-init.js`).
- `prefers-reduced-motion` вимикає анімації. Каруселей немає.
- Акордеони — нативні `<details>/<summary>` (працюють без JS).
- Меню — патерн disclosure (`aria-expanded`, `aria-controls`), Esc закриває спливні панелі й повертає фокус. Мобільне меню — модальний діалог: фокус переходить усередину, решта сторінки отримує `inert`, при розширенні вікна до десктопа меню закривається.
- **Без JS** (`<html>` без класу `js`): кнопки-перемикачі сховані, мобільне меню показане звичайним блоком із розгорнутими підрозділами, у десктопному меню замість кнопок — посилання на лендинги розділів. Панель доступності без JS не показується (вона сама працює на JS).
- Фокус посилань і кнопок задано поза `@layer` з `!important`: темний текст на жовтому завжди, навіть якщо в елемента є `text-white`.
- `forced-colors` (Windows High Contrast): натиснуті й розгорнуті перемикачі мають рамку, стан кнопок панелі доступності дублюється галочкою.
- Попередження у виділених блоках мають прихований префікс «Увага:» / «Важливо:», щоб тип читався не лише кольором.
- Посилання на зовнішні сайти відкриваються в новій вкладці з прихованим для очей попередженням; документи мають тип і розмір у тексті посилання.

## Поточний стан шапки й футера
`base.html` уже використовує шапку й футер, але меню (`nav_items`), контакти (`site_info`) і перемикач мов (`lang_links`) зараз передає лише `/styleguide/`. На справжніх сторінках вони порожні, доки у фазі 2 не з'являться SiteSettings, snippet меню й context processor. Так і має бути до фази 2.

## JavaScript
Замість Alpine.js — власний `static/js/site.js` (~5 KB без мініфікації, без залежностей). Причини: потрібна лише логіка disclosure й панелі доступності; немає `eval`/inline-обробників, тож суворій CSP (фаза 8) не потрібні `unsafe-eval` чи `unsafe-inline`. Якщо з'явиться складніша інтерактивність, можна підключити `@alpinejs/csp`.

## Іконки
Lucide (ISC), inline SVG у `templates/components/icons/`. Виклик: `{% include "components/icon.html" with name="phone" class="size-5" %}`. Іконки декоративні (`aria-hidden`), зміст передає текст поруч.
