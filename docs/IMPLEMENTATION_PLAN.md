# Implementation Plan — вебсайт Управління соціальної та ветеранської політики Лубенської міської ради

> Стек, архітектура та інструменти Claude Code: див. [STACK.md](STACK.md).

## Контекст

Потрібен окремий офіційний сайт Управління соціальної та ветеранської політики Лубенської міської ради (далі — УСВП). Репозиторій `C:\Users\VikTOR\PycharmProjects\usvp` порожній (лише `.venv` на Python 3.12.10 та `.idea`), тож проєкт створюється з нуля на Django.

Вхідні умови від замовника:
- Реєстрації відвідувачів немає; входять лише **адміністратор** і **контент-менеджер**.
- Зовнішніх інтеграцій немає, лише **посилання** на Facebook-сторінку та Google (Google Maps / профіль організації).
- **Українська версія основна, є англомовна.** Домену поки немає. Старий контент не переносимо.
- Структура: Головна, Соціальний напрямок, Ветеранська політика, ВПО, Публічна інформація, Новини, Оголошення, Контакти, Пошук.

## 1. Нормативні вимоги, що впливають на сайт

| Документ | Що з нього випливає для сайту |
|---|---|
| ЗУ «Про доступ до публічної інформації» (ст. 15, 18) | Розділ «Публічна інформація»: обов'язкове оприлюднення, **система обліку публічної інформації** (реєстр документів), порядок подання запитів, звіти про розгляд запитів |
| ЗУ «Про забезпечення функціонування української мови як державної», ст. 27 | Українська версія **відкривається за замовчуванням** (`/`); EN за обсягом і змістом **не більша** за UA; перемикач мов на кожній сторінці |
| ДСТУ EN 301 549:2022 (≈ WCAG 2.1 AA), політика безбар'єрності | Доступність WCAG 2.1 AA (ціль — 2.2 AA), сторінка «Заява про доступність», налаштування шрифту й контрасту |
| ЗУ «Про звернення громадян» | Графік особистого прийому, адреси та способи звернення (без онлайн-форм: відвідувачі не реєструються) |
| ЗУ «Про захист персональних даних» | Політика конфіденційності. Згоди на фото/ПІБ працівників. Без трекерів банер cookies не потрібен |
| Бюджетний кодекс, ст. 28 | Паспорти бюджетних програм, звіти про їх виконання, кошториси |
| ЗУ «Про запобігання корупції» | Підрозділ «Запобігання корупції» (уповноважена особа, повідомлення) |
| ПКМУ № 835 (відкриті дані) | Посилання на набори на data.gov.ua (лише посилання, без інтеграції) |
| ПКМУ № 3 від 04.01.2002 (орієнтир) | Типовий перелік відомостей: положення, структура, керівництво, контакти, графік |
| Кібербезпека, ТЗІ | HTTPS, 2FA для адмінів, журнал дій, резервні копії. Вимоги до хостингу погодити з міськрадою |

Домен: рекомендую зону **`.gov.ua`** (наприклад, `usvp.lubny.gov.ua` або субдомен сайту міськради). Реєстрацію має ініціювати міська рада.

## 3. UI/UX і дизайн

**Методологія:** task-first / life-events (як GOV.UK і Дія): людина приходить із задачею («я ветеран», «я ВПО», «потрібна допомога»), а не для того, щоб вивчати структуру управління. Mobile-first, бо більшість відвідувачів заходить із телефона.

**Візуальна мова**
- Офіційна, спокійна, без «рекламності». Орієнтир — дизайн-принципи Дія / gov.ua.
- Палітра: глибокий синій (primary, основа ідентичності), жовтий лише як акцент/фокус, нейтральні сірі; для ветеранського розділу допустимий приглушений оливковий акцент. Контраст тексту ≥ 4.5:1, великих елементів ≥ 3:1.
- Шрифт e-Ukraine: базовий 18px, міжрядковий інтервал 1.5, ширина рядка ≤ 75 символів.
- Токени (CSS variables / Tailwind theme): кольори, відступи на 8-pt сітці, радіуси, тіні.
- Іконки: єдиний набір (Lucide/Heroicons, inline SVG).

**Шапка:** герб Лубен + повна офіційна назва · перемикач UA/EN · пошук · кнопка «Доступність» (розмір шрифту, високий контраст, підкреслення посилань; зберігається в `localStorage`) · головне меню (mega-menu на десктопі, повноекранне на мобільному).

**Головна**
1. Банер термінового оголошення (вмикається в налаштуваннях).
2. Hero: назва, короткий опис, пошук.
3. «Що вам потрібно?»: 6–8 плиток (Ветеранам · ВПО · Соціальні послуги · Пільги · Реабілітація · Графік прийому · Контакти · Публічна інформація).
4. Актуальні оголошення (3).
5. Новини (3–6).
6. Програми / ключові послуги.
7. Контакти й графік прийому + посилання на Google Maps.

**Футер:** контакти, графік, посилання (Лубенська міська рада, Facebook, Google Maps), службові сторінки, дата останнього оновлення, © і ліцензія контенту.

**Компоненти:** хлібні крихти, бокова навігація розділу, картка послуги, акордеон FAQ, таблиця документів (іконка типу, розмір, дата), картка людини, пагінація, «на цій сторінці» (TOC для довгих текстів), кнопка «Нагору», сторінки 404/500 з пошуком.

**Доступність (обов'язково):** семантичний HTML і landmarks, «Перейти до змісту», видимий focus, повна клавіатурна навігація, ARIA для меню й акордеонів, alt-тексти обов'язкові в адмінці, `lang` на сторінці та фрагментах, `prefers-reduced-motion`, без карусель-автопрокрутки. PDF публікувати з текстовим шаром і, де можливо, дублювати ключовий зміст HTML-текстом.

**Продуктивність:** LCP < 2.5s на 4G, Lighthouse ≥ 90 за всіма 4 категоріями, JS < 50 KB.

## 5. Верифікація

- `python manage.py check --deploy` без попереджень на prod-налаштуваннях.
- `pytest`: моделі, шаблони (кожен тип сторінки рендериться з 200), права ролей (контент-менеджер не бачить налаштувань і користувачів), мова (`/` віддає UA, `/en/` віддає EN, hreflang коректні).
- Playwright E2E: навігація меню, пошук, перемикач мов, мобільне меню, панель доступності. **axe-core без порушень рівня serious/critical** на всіх шаблонах.
- Lighthouse CI ≥ 90 (Performance, Accessibility, Best Practices, SEO).
- Ручна перевірка: клавіатура, NVDA, зум 200%, ширина 320px.
- Сценарій контент-менеджера: створити новину, оголошення з «діє до», послугу, запис реєстру, переклад EN, опублікувати, знайти через пошук.
- Безпека: `/security-review`, перевірка заголовків (securityheaders.com на staging), обмеження типів і розмірів файлів, спроба brute-force блокується.
- Відновлення з бекапу на чистому середовищі.
